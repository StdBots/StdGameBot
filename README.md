## ⚡ Features & Gaming Modes

- **⭕ Tic-Tac-Toe (XO Duel):** Interactive 3x3 inline board with real-time multiplayer turns in groups or private chat.
- **✂️ Rock-Paper-Scissors:** Blind weapon selection duel with coin pot payouts.
- **🎰 Casino Slots:** 3-reel animated slot machine with 10x jackpot multipliers (777).
- **🎲 Animated Dice Duel:** Roll against the bot with wagered coins and instant payouts.
- **🔢 Number Guessing:** Fast-paced 1-100 guessing challenge with dynamic higher/lower hints.
- **🧠 Math Speed:** Rapid 45-second arithmetic tests for bonus XP and coins.
- **💰 Economy & Gamification:**
  - Starting bonus coins for all new players.
  - `/daily` 24-hour reward system with streak tracking.
  - XP progression with rank titles (Novice, Veteran, High Roller, Grandmaster, Legend).
  - Public top 10 richest and winning leaderboards.
  - Peer-to-peer coin transfers via `/transfer`.

## 🕹️ Command Reference

| Command | Description |
|---|---|
| `/start` | Welcome greeting and quick gaming menu |
| `/games` | Interactive category selector |
| `/daily` | Claim 24-hour free coin reward |
| `/wallet` | View your current balance |
| `/profile` | Detailed combat stats and rank card |
| `/leaderboard` | View top richest players |
| `/dice [bet]` | Roll animated dice against bot |
| `/slots [bet]` | Spin the casino slot machine |
| `/ttt [bet]` | Create a 3x3 Tic-Tac-Toe challenge |
| `/rps [bet]` | Create a Rock-Paper-Scissors duel |
| `/guess [bet]` | Start 1-100 Number Guessing session |
| `/math [bet]` | Start speed arithmetic test |
| `/transfer <id> <amt>` | Send coins to another player |
| `/stats` | Admin engine analytics |
